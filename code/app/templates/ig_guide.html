Instagram bo'limi yo'riqnomasi

Ulashdan boshlab kundalik ishgacha. Meta menyulari vaqti-vaqti bilan o'zgaradi: nomlari biroz farq qilsa, ma'nosi bo'yicha qidiring.

1. Nimalar kerak

  • Instagram sahifa Professional bo'lishi shart: Instagram ilovasi → Sozlamalar → «Akkaunt turi va asboblar» → «Professional akkauntga o'tish» (Business yoki Creator, ikkalasi ham bo'ladi).
  • Facebook sahifasi kerak emas. Faqat Meta dasturchilar kabinetiga kirish uchun oddiy Facebook akkaunt kerak (bir martalik, jamoadan bitta odamda bo'lsa yetadi).
  • Kompyuter doimiy yoqiq va dastur (run.bat) ochiq turadi: statistika, eslatma va joylash shunda ishlaydi.

2. Meta ilovasini yaratish (bir marta, ~10 daqiqa, bepul)

  1. developers.facebook.com → kiring → «Get Started»/«My Apps» → Create App.
  2. Nom bering (masalan, «SMM Panel»), foydalanish turida Instagram bilan bog'liq variantni tanlang («Manage messaging & content on Instagram» yoki «Other» → Business turi).
  3. Ilova ichida Add product → Instagram → API setup with Instagram login bo'limini oching.
  4. Ilova Development (rivojlantirish) rejimida qolaveradi: o'z va tester akkauntlaringiz uchun Meta tekshiruvi (App Review) kerak emas.
  5. Har bir Instagram sahifani tester qiling: ilova → App roles → Roles → Add People → Instagram Tester → sahifa username'ini yozing. Keyin o'sha Instagram akkauntga kirib: Sozlamalar → «Veb-saytlar uchun ruxsatlar» (Apps and websites) → Tester taklifnomalari → qabul qiling. Jamoa sahifalarni boshqargani uchun buni o'zingiz bajara olasiz.

3. Sahifani ulash

1-usul (tavsiya, eng oson): token bilan. Meta ilovasi → Instagram → API setup with Instagram login → «Generate access token» bo'limida sahifangiz yonidagi Generate token tugmasi → sahifa akkauntiga kirib ruxsat bering (uchala ruxsat: basic, content publish, manage insights) → uzun tokenni nusxalang → Sahifalar → Token maydoniga qo'yib «Ulash». Dastur akkaunt Professional ekanini tekshiradi va ma'lumotni yig'a boshlaydi.

2-usul: «Instagram orqali kirish». Shu sahifadagi Instagram App ID va App Secret (Meta ilovasining Instagram bo'limida ko'rinadi; bosh ilova ID'sidan farq qiladi) ni Sozlamalarga kiriting. Meta dasturida «Valid OAuth redirect URIs» ga {{ conf.redirect }} ni qo'shing (Sozlamalarda bir xil bo'lsin). Keyin Sahifalar → «Instagram orqali ulash». Agar Meta http:// manzilini qabul qilmasa, 1-usuldan foydalaning: u hamma holatda ishlaydi.

  • Token 60 kun yashaydi. Dastur ochiq bo'lsa, muddati tugashiga 10 kun qolganda o'zi yangilaydi. Dastur 60 kundan ortiq o'chiq tursa, token o'ladi: qaytadan Generate token qiling.
  • Sahifani o'chirish: Sahifalar → «O'chirish» (nom yozib tasdiqlanadi). Sahifaning hamma ma'lumoti dasturdan o'chadi, Instagram'dagi akkauntga tegilmaydi.
  • 3 tadan ortiq sahifa ham qo'shsa bo'ladi: har biri alohida tester bo'ladi va yuqoridagi sahifa tanlagichidan almashtirasiz.

4. Kundalik ish tartibi

  1. Profil va maqsad: sahifa sohasi, auditoriya, ohangni yozing. «AI maqsad taklif qilsin»ni bosing: AI real maqsad tuzadi; o'zgartirib «Maqsadni saqlash». Asosiy maqsad: sahifani o'stirish.
  2. G'oya va ssenariy: g'oya so'rang (AI statistika, maqsad va rejadagi postlarni hisobga oladi). Yoqqanini «Rejaga qo'shish»; Reels bo'lsa «Video ssenariy yozdirish» (kadrma-kadr, ovoz, ekrandagi yozuv, tavsif).
  3. Kontent reja: rasm/video qo'shing, vaqt qo'ying. O'ngda Instagram'dagi ko'rinish chiqadi. «AI tahlil» takliflar beradi (sizning matningiz o'zgarmaydi); «Vaqt taklifi» eng yaxshi 3 vaqtni beradi (rejadagi postlar va kunlik me'yor hisobga olinadi).
  4. Joylash: Eslatma rejimida vaqti kelganda bildirishnoma chiqadi, reja sahifasida tavsifni nusxalab, faylni yuklab Instagram'da joylaysiz va «Joylandi ✓» bosasiz. Avto rejimda dastur o'zi joylaydi.
  5. Reja nazorati: haftada bir «Rejani tekshirish»: AI tezlik, format balansi, bo'shliqlarni aytadi va keyingi g'oyalarni vaqti bilan beradi.
  6. Statistika / Postlar natijasi / AI tahlil: nima ishlayapti va keyingi 7 kun uchun harakatlar.
  7. Reklama (target): qaysi postga Boost yoqish foydali, qancha byudjet va qaysi auditoriya. Reklamani Instagram ilovasida o'zingiz yoqasiz.

5. Avto joylash (ixtiyoriy)

  • Instagram faylni sizning kompyuteringizdan ola olmaydi: u internetdagi ochiq havoladan yuklab oladi. Shuning uchun faqat avto joylash uchun bepul cloudflared (Cloudflare Quick Tunnel) ishlatiladi, hisob ochish shart emas.
  • Sozlamalar → «cloudflared'ni yuklab olish» → rejimni «Avto» qiling → Diagnostika → «Tunnel sinovi». Sinov o'tsa tayyor.
  • Tunnel faqat joylash paytida ochiladi, faqat bitta faylga bir martalik havola beradi, qolgan sahifalaringiz tashqaridan ochilmaydi; joylangach yopiladi.
  • Avto joylash ishlamasa, post «Xato» holatida qoladi va bildirishnoma chiqadi: eslatma rejimidagidek qo'lda joylashingiz mumkin.
  • Talablar: rasm JPEG (dastur o'zi o'giradi), Reels uchun MP4/MOV vertikal video, karusel 2-10 fayl. Instagram sutkasiga ~50-100 ta API post limiti qo'yadi.

6. Statistika haqida bilish kerak

  • Yangi ko'rsatkichlar Instagram'da 48 soatgacha kechikishi mumkin. Obunachi soni dastur har kuni saqlab boradi (shuning uchun dastur ochiq turgani muhim).
  • Auditoriya (yosh, jins, shahar) Instagram tomonidan faqat 100 va undan ko'p obunachida beriladi.
  • Faqat umumiy raqamlar yig'iladi; obunachilarning shaxsiy ro'yxati yig'ilmaydi. Raqobatchilar tahlili yo'q: Instagram rasmiy API'si boshqalarning sahifasini bermaydi.
  • Reklama (target) Instagram API orqali boshqarilmaydi: dastur tavsiya beradi, reklamani qo'lda yoqasiz.

7. Muammolar

  • «Token yaroqsiz» (190): Meta'da yangi token yarating va Sahifalar'da qayta kiriting (o'sha akkaunt bo'yicha eskisi almashadi).
  • «Professional emas»: Instagram ilovasida akkaunt turini o'zgartiring.
  • Statistika bo'sh: yangi akkauntda 48 soat kuting; Diagnostika → «Statistika (insights)» ruxsatni ko'rsatadi; tokenda manage_insights bo'lishi kerak.
  • Joylab bo'lmadi: Diagnostika → «Joylash ruxsati» va «Tunnel sinovi». Antivirus cloudflared'ni to'sgan bo'lishi mumkin.
  • AI ishlamayapti: OpenAI kaliti va hisobdagi mablag'ni tekshiring (Kanallarim → Sozlamalar).
  • Tushunarsiz xato: Tizim tahlili → Instagram bo'limi va «AI xulosa so'rash».
