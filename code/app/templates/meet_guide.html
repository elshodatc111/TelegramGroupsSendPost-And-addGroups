Yo'riqnoma

Majlislarni birinchi marta sozlash: Google Cloud, Telegram akkaunt, o'qituvchi, jadval va muammolar.

{{ ic('link') }} 1. Google Cloud sozlamasi (bir marta, ~10 daqiqa)

Domen kerak emas. Shaxsiy Gmail yetadi; kalit faqat shu kompyuterda (shifrlangan) saqlanadi.

  1. Loyiha oching. console.cloud.google.com ga host Gmail bilan kiring → yuqoridagi loyiha tanlagich → New project → nom: TelegramMajlis → Create.
  2. Ikkita API'ni yoqing. APIs & Services → Library: Google Meet REST API → Enable; keyin Google Calendar API → Enable.
  3. OAuth rozilik ekrani. Google Auth Platform (yoki APIs & Services → OAuth consent screen) → Get started: ilova nomi Majlislar, qo'llab-quvvatlash emaili — o'zingiznikи, Audience: External. Email'ni Test users ga qo'shing.
  4. Ruxsatlar (Data Access → Add or remove scopes). Quyidagilarni qo'shing:
    {% for s in scopes %}
    {{ s }}
    {% endfor %}
  5. OAuth kalit. Clients → Create client (yoki Credentials → Create credentials → OAuth client ID) → turi: Desktop app → Create. Client ID va Client secret ni nusxalang va Sozlamalarga kiriting. (Desktop turi 127.0.0.1 qaytish manzilini o'zi qabul qiladi: {{ redirect_uri }}.)
  6. Ilovani Production holatiga o'tkazing — MUHIM. Audience → Publish app → Confirm. Aks holda ilova «Testing» holatida qoladi va token 7 kundan keyin o'chadi (darslar to'xtab qoladi). Production'da tasdiqlanmagan ilova ogohlantirish ko'rsatadi: Advanced → Go to Majlislar (unsafe) — bu o'z ilovangiz, xavfsiz. Production'ga o'tgandan keyin Google'ga qayta ulang.
  7. Ulang. Sozlamalar → Google'ga ulash → Gmail'ni tanlang → barcha ruxsatlarni belgilab Continue. So'ng Google diagnostikani ishga tushiring: har imkoniyat «Ishlaydi» yoki sababi bilan ko'rinadi.

Gmail va 60 daqiqa

Shaxsiy Gmail'da Meet uchrashuvi 60 daqiqa bilan cheklanadi. Dars 60 daqiqadan uzun bo'lsa, yaratishda ogohlantirish chiqadi va Tizim tahlilida «Meet limiti: 60 daqiqa (Gmail)» ko'rinadi. Host akkauntni Workspace'ga almashtirish: Sozlamalar → «Uzish» → qayta ulash va host turini Workspace deb belgilang.

{{ ic('send') }} 2. Telegram akkaunt

  1. Group Post → Sozlamalar'da API ID / API HASH kiritilgan bo'lsin (my.telegram.org).
  2. Majlislar → Telegram akkaunt: alohida raqam kiriting, kodni tasdiqlang (Group Post va Kanallarim raqamlaridan boshqa).
  3. Bu akkauntni o'quvchilar guruhlariga qo'shing (yozish huquqi bilan). Guruhlar sahifasida «Telegramdan tanlash» orqali guruhni biriktiring.
  4. Admin @username ni Sozlamalarga kiriting: o'qituvchi kechiksa, xabar yetmasa, dars tugasa shu odamga xabar boradi.

{{ ic('cap') }} 3. O'qituvchi qo'shish

  1. O'qituvchilar: ism, Gmail (Meet'da avtomatik co-host bo'ladi, kalendar ulashiladi), Telegram @username (havola shaxsiy xabar bilan boradi), telefon, izoh.
  2. O'qituvchi akkaunti Telegram'da shu @username bilan topilishi va Majlislar akkauntini bloklamagan bo'lishi kerak.
  3. Guruh sahifasida o'qituvchini tanlang.

{{ ic('repeat') }} 4. Jadval

  1. Guruhni oching → Haftalik jadval: hafta kunlari (odatda 3-6 ta), vaqt (Toshkent), davomiylik → Jadvalga qo'shish.
  2. Dastur keyingi {{ 7 }} kun (Sozlamalarda o'zgaradi) uchun har dars uchun yangi Meet xonasi (havola ochiq), kalendar yozuvi va co-host yaratadi. Har guruhning o'z Google Calendar'i bor; bosh sahifada hamma guruhlar bitta kalendarda.
  3. Dars boshlanishidan 10 daqiqa oldin o'qituvchiga shaxsiy xabar, 5 daqiqa oldin guruhga havola; 60 va 10 daqiqa oldin guruhga eslatma (Sozlamalarda o'zgaradi).
  4. Bekor qilish / ko'chirish: «Amallar» tugmasi — guruhga va o'qituvchiga avtomatik xabar ketadi, kalendar yangilanadi.
  5. Begona kirsa, o'qituvchi Meet ichida o'zi chiqaradi. Platformada chiqarish tugmasi va begonani aniqlash tizimi yo'q: faqat «ko'p odam» / «yangi nom» xabari keladi.
  6. Davomat dars davomida har 30-60 soniyada yangilanadi. Bir odamning turli ismlarini Birlashtirish orqali bog'lang. Yozuv (record) havolasi qo'lda kiritiladi.

{{ ic('alert') }} 5. Muammolar

«API yoqilmagan» / SERVICE_DISABLED

Google Cloud → Library'da Meet REST API va Calendar API yoqilganini tekshiring (2-qadam). Yoqqandan keyin 1-2 daqiqa kuting.

Token 7 kundan keyin o'chdi (invalid_grant)

OAuth ilovasi «Testing» holatida edi. Audience → Publish app; so'ng Sozlamalarda qayta ulang.

«Access blocked / app not verified»

Email Test users'da yo'q (Testing) yoki ogohlantirish ekranida Advanced → Go to ... (unsafe) bosilmagan.

Co-host qo'shilmadi

O'qituvchining Gmail manzili noto'g'ri yoki Google akkaunti yo'q. Diagnostika «co-host» qatoridagi xatoni ko'rsatadi. Co-host bo'lmasa ham o'qituvchi havola orqali kiradi, lekin begonani chiqarish uchun u host (siz) tomonidan Meet ichida tayinlanishi kerak bo'lishi mumkin.

Havola Telegram'ga yetmadi

Ogohlantirishlarda xabar matni va nusxalash tugmasi bor: qo'lda yuboring. Sabab: @username noto'g'ri, o'qituvchi maxfiylik sozlamasi, akkaunt guruhdan chiqarilgan yoki Telegram cheklovi.

Davomat ko'rinmayapti

Diagnostikada «Davomat API» ni tekshiring. Akkauntsiz mehmonlar «Noma'lum» yoki Meet'dagi nom bilan chiqadi. O'qituvchi aniqlanmasa, dars sahifasida «Bu o'qituvchi» tugmasi bilan belgilang (keyingi darslarda eslab qolinadi).

Dars 60 daqiqada to'xtadi

Gmail cheklovi. Workspace akkauntga o'ting yoki dars davomiyligini qisqartiring.
