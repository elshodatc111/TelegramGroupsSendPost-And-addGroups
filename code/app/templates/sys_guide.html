Ishga tushirish yo'riqnomasi

Loyihani noldan ishlatish va muammo chiqqanda nima qilish kerak.

← Tizim tahlili

1. Har kungi ishga tushirish

  1. C:\TelegramGroupPost\run.bat ni ikki marta bosing. U XAMPP MySQL'ni o'zi ishga tushiradi va brauzerda http://127.0.0.1:8000 ni ochadi.
  2. Oyna ochiq turishi kerak: yopsangiz rejalashtirilgan postlar, statistika va hisobotlar to'xtaydi.
  3. Bu sahifadagi «Qayta tekshirish» hammasi joyidaligini ko'rsatadi.

2. Birinchi marta sozlash

  1. Sozlamalar: Telegram API ID/HASH (my.telegram.org) va OpenAI kaliti.
  2. Kanallarim → Akkaunt: kanal admini bo'lgan raqamni ulang.
  3. Kanallar: kerakli kanalni biriktiring, Kanal profilida biznes ma'lumotlari, «Brend va aloqa» (telefon, manzil, mo'ljal, 3 rang, logotip) va lid havolasini kiriting.
  4. Kuzatuv havolasi (ixtiyoriy, bepul): code\tools\CLOUDFLARE.md bo'yicha Cloudflare Worker'ni ulang. Shunda har post uchun alohida havola chiqadi va bosilishlar sanaladi.

3. Ixtiyoriy qismlar

  • Video → matn: code\tools\install_whisper.bat (ffmpeg + faster-whisper). Video karta bo'lsa tezroq.
  • Lokal rasm yaratish: code\tools\install_imagegen.bat (PyTorch CUDA + diffusers, ~3 GB). Birinchi rasmda model yuklanadi (~2 GB), keyin internetsiz ishlaydi. Yangilash yoki o'rnatishdan so'ng dasturni qayta ishga tushiring.
  • Bularsiz ham dastur ishlaydi: transkripsiya OpenAI orqali, rasm esa gradient fon bilan chiqadi.

4. Muammo chiqsa

  • MySQL ishlamayapti / «Aria crashed»: XAMPP Control Panel'da MySQL'ni to'xtating, C:\xampp\mysql\data ichidagi mysql papkasini toza backup papkasidagi nusxa bilan almashtiring, qayta Start qiling. Bazadagi ma'lumotlarga tegilmaydi.
  • Akkaunt «Ulanmagan»: Akkaunt sahifasida «Qayta ulash», kodni kiriting.
  • Post yuborilmadi: Kontent reja sahifasidagi xato matniga qarang; ko'pincha akkauntda post yuborish huquqi yo'q yoki internet uzilgan.
  • Rasm qora chiqdi: GTX 16xx kartalarda bo'lishi mumkin; dastur o'zi aniqroq rejimda qayta urinadi. Yordam bermasa «Gradient fon» ni tanlang.
  • Bildirishnoma kelmayapti: Windows «Fokus/Bezovta qilmang» rejimini o'chiring, Ogohlantirishlar sahifasida «Bildirishnomani sinash».
  • Tushunarsiz xato bo'lsa: Tizim tahlili → «AI xulosa so'rash».
